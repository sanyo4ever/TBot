# TBot 3.4.6a

Independent maintenance release based on author release [3.4.6](https://github.com/0xE232FE/TBot/releases/tag/3.4.6), with reviewed develop-branch changes and selected community fixes. `fork-version.json` records the upstream release and source commits. Future author releases will be reviewed before adoption; our next maintenance revision on this base is `3.4.6b`.

## Included fixes

- Strict OGame13 `checkTarget` compatibility: successful modern responses no longer become `target is not ok`, while explicit failures/errors still stop before dispatch.
- Null-safe running-profile listing and the Admiral expedition-slot argument correction.
- AutoDiscovery recovery and multi-origin behavior, plus expedition priority/return-aware scheduling, adapted from [TBotPR56](https://github.com/0xE232FE/TBot/pull/56) and [its recovery follow-up](https://github.com/Cheeeh/TBot/pull/1), with expanded worker regression coverage.
- AutoDiscovery resumes after a daily allowance reset and accepts both existing colonization-priority setting names, preserving canonical-key precedence.
- Selected OGame13 galaxy, recall, eventlist, lifeform-bonus, trader and fleet-return compatibility from [ogame.modPR169](https://github.com/0xE232FE/ogame.mod/pull/169), with stricter response validation.
- The local captcha-solver endpoint returns JSON on success and propagates solve/login errors; the existing manual solver is retained.
- Production bonus extraction from [ogame.modPR167](https://github.com/0xE232FE/ogame.mod/pull/167), plus reviewed highscore, LifeformLevels and GetTechs compatibility from [upstreamPR161](https://github.com/alaingilbert/ogame/pull/161). GetTechs does not acquire a Commander/empire requirement.
- .NET10 build/CI alignment and fork version labels visible in the window title. Packages include their runtime and the pinned Go backend.

## Selection boundaries

Existing resourcesbar routing, Plasma Terraformer11212 and our stricter fleet-target validation are retained rather than replaced by duplicate PR hunks. The broad PoW/CAPTCHA JavaScript/fingerprint changes in PR169 are excluded: they introduce uncancellable work, guessed browser instrumentation, new dependencies/toolchain requirements and insufficient regression coverage. The existing bad-credentials sentinel remains intact.

Legacy production-bonus fixtures do not establish complete v13 production/phalanx bonus support. Automated protocol fixtures are synthetic or sanitized source fixtures; they are not a claim of live-game validation. No game login, live fleet send or real Telegram request is used by the release tests.

## Installation

Validation before packaging: **53 C# cases, 643 Go test-pass cases and 9 version-policy tests passed**, with independent code review of the combined changes. CI tests both projects again and builds all seven packages before creating the release. Live-account actions are not part of these checks. Existing compiler/dependency warnings remain visible in the build logs.

Choose the ZIP for your platform. Each package includes BUILD-INFO.txt and fork-version.json with exact source provenance; SHA256SUMS covers all seven packages. Keep account settings private and outside public source/release assets. For a local upgrade, stop the old client before starting the new one; retain the old folder for rollback.
